This package answers:

> Given a top's physical properties and initial conditions, how long will it
> spin before noticeable wobble begins?

It combines a corrected orientation-aware rigid-body simulation with explicit
wobble, stopping, and chaos events; reproducible sweeps; right-censored
statistics; and interpretable model discovery.

The [project README](https://github.com/ryan-charette/Computational-Dynamics-of-a-Spinning-Top#readme)
provides installation and command examples.
